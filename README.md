# 甲醇量化研究学习工具

从公共日线数据开始，学习行情校验、均线信号、交易成本和回测。核心使用 Python 3.10+ 标准库，无需第三方依赖或行情 API 密钥；新增在线期权与基本面模块可选安装 AKShare。

## 从这里开始

在仓库目录运行：

```bash
python -m unittest discover -s tests -v
python -m methanol fetch
python -m methanol check
python -m methanol backtest --fast 10 --slow 30 --cost-bps 5
```

`fetch` 默认下载新浪财经甲醇主力连续 `MA0`，写入 `data/ma_daily.csv`。也可使用 `--symbol MA2701 --output data/ma2701.csv` 请求单合约（接口是否覆盖此合约需实际核验）。下载会覆盖指定输出文件及其来源记录；希望保留旧版本时请指定不同文件名。下载失败不会自动生成假行情。

数据下载需要允许 HTTPS 域名 `stock2.finance.sina.com.cn`。郑商所官网 `www.czce.com.cn` 可用于核验合约规则及官方数据。若出现 `Tunnel connection failed: 403 Forbidden`，请在云环境设置审核、保存网络许可并在需要时发布环境，再重试。Issue #1 新增交易所逐合约采集适配器，最新实测见文末。

下载成功时同时保存原始 JSONP、抓取时间、请求地址、日期范围、行数，以及原始响应和 CSV 的 SHA-256。公共接口可能改变、缺失历史或停止服务；以实际返回的日期范围为准，不保证最新、不保证与交易所一致。数据仅供本地学习，未随代码提交或重新分发。

## 查看研究结果

打开生成的 `reports/ma/report.html`（不需要启动 Web 服务）。报告还包含：

- `summary.json`：累计收益、年化收益、波动、夏普比率、最大回撤、交易数量。
- `curve.csv`：信号仓位、区间收益、策略和基准净值、回撤。
- `trades.csv`：每次入场、离场及扣除成本的区间收益。

`data/` 与 `reports/` 被 Git 忽略。本地 CSV 也能回测：

```bash
python -m methanol backtest --input /path/to/ma.csv --output reports/custom
```

必需字段：`date,open,high,low,close`；可选字段：`volume,hold,settle`。日期须是 `YYYY-MM-DD`，重复日期、缺失或非有限价格、非法 OHLC 关系会报错。读取时按日期排序，不自行填补缺失交易日或价格。

## 学习顺序与模型边界

1. **观察数据**：记录样本日期、价格区间和缺失情况；确认是主力连续还是单合约。
2. **理解策略**：10 日均线高于 30 日均线时持有，否则空仓。上一交易日收盘生成信号，下一交易日开盘执行。
3. **理解记账**：以开盘至下一开盘为一个收益区间，最后一日以收盘结束并平仓；手续费按进出各一次扣除。曲线日期是区间开始日，`interval_end_date` 是区间结束日。基准为同一期间无杠杆持有价格指数，暖机期策略空仓，基准持有。
4. **改变假设**：比较参数与成本敏感性，预先划分训练和测试日期，避免反复挑选表现最好的参数当成预测能力。现可使用 `research` 进行固定参数的历史时间划分评估，详见下文。
5. **进入真实期货建模**：后续使用逐合约数据补充换月、合约乘数、每手手续费、保证金、逐日结算、涨跌停和成交限制。

本版计算的是**无杠杆价格指数研究收益**，不是实际期货账户盈亏。主力连续可能有拼接跳空，无法代表可以直接交易的单一合约；本版不自动修正这些跳空，交易成本的基点假设也不等于真实收费。年化采用 252 个交易日，最大回撤只在区间端点计算，夏普使用零无风险利率。请勿将结果直接用于下单。

## 可信度评估：完整性、日期与时间划分

```bash
# 校验 CSV 与原始响应的 SHA-256，并输出数据年龄、跳空和成交量检查
python -m methanol check

# 仅评估指定日期；此前历史只用于均线，不计入账户收益
python -m methanol backtest --start 2022-01-01 --end 2026-10-12 --output reports/period

# 固定10/30均线，2022年前训练，2022年及以后测试，比较成本情景
python -m methanol research --split-date 2022-01-01 --fast 10 --slow 30 --cost-bps 5
```

打开 `reports/research/report.html`，可分别查看训练与测试报告，以及测试期单边 0、5、10、20 基点的成本压力结果。`research.json` 保存参数、分界日期、数据指纹、来源、质量检查与限制。修改基准成本时，该成本也会纳入情景集合。

训练期在分界前最后交易日**收盘**强制结束，不使用测试期的开盘价；测试期重新从现金开始，之前历史仅用于均线。没有自动参数搜索。`--start`、`--end` 也可用于 `research`：开始日期必须早于分界，结束日期必须覆盖测试区间。

**整段历史已经被查看过，因此这属于回顾性的时间划分评估，不能称为从未见过数据上的独立样本外成功。** 下一步应冻结研究假设，在新数据或预先保留的独立数据上验证，不能通过反复修改分界或参数来追求好看的结果。

### 早期时间划分结果（历史检查点）

使用同一份 2,857 根行情、固定 10/30 均线、单边 5 基点成本：

| 区间 | 累计收益 | 最大回撤 | 完整交易 |
|---|---:|---:|---:|
| 2014-12-24 至 2021-12-31 | 28.63% | 32.06% | 34 |
| 2022-01-04 至 2026-10-12 | -15.86% | 37.48% | 24 |

测试区间即使使用零成本，仍亏损约 13.82%。这说明全样本的正收益不能证明策略在较近的历史区间仍有效；不应仅凭原全样本结果判断策略可用。

### 完整性规则

- 来源记录存在时，CSV、原始响应哈希、日期范围和行数必须匹配；不匹配时直接失败，不继续生成报告。
- 自备 CSV 没有来源记录时仍可研究，但报告明确标记 `unverified`，不会伪造公共市场来源。
- 哈希仅证明本地文件一致，不证明行情的真实性或准确性；还需要第二来源或交易所数据核验。
- 数据年龄按上海时区的自然日计算，未接入交易所日历，不将节假日认定为缺失交易日。
- 大跳空、缺失和零成交量只报告，不自动删除或修补，不改变原始行情。

新增测试覆盖数据篡改、来源记录损坏、训练与测试边界隔离、历史暖机、日期筛选及成本情景。全部 **25 项测试**通过。

## 方向准确率：滚动预测与基准比较

```bash
python -m methanol forecast
```

打开 `reports/forecast/report.html`。`predictions.csv` 保存逐日概率、方向、实际标签与对应日期；`forecast.json` 保存模型定义、数据哈希、每次训练的起止日期、混淆矩阵、年度指标及基准差值的不确定性。

这里的“准确率”明确指**上一日收盘后预测当日开盘到下一交易日开盘是否上涨**，不是交易胜率。平盘归入非上涨，模型预测非上涨时收益模拟为空仓。使用相同日期比较：

- 固定设计的滚动 L2 逻辑回归：1/5/20 日价格变化、20 日波动和上一日成交量相对20日均量。
- 原有 10/30 日均线的二元方向信号。
- 始终预测上涨。
- 训练窗口中占多数的方向。

模型使用最近504个已知标签，每63个交易日重新训练；标准化只在训练窗口计算，阈值固定0.5。预测第 i 日时，最后训练样本是 i-2，标签截止 i-1 开盘；不使用尚不可知的 i 日开盘来训练。没有自动搜索参数，也没有根据历史比较结果选取“赢家”。

同时展示平衡准确率、上涨预测精确率、概率 Brier 评分、扣除成本后的价格指数收益和回撤。类别单一时平衡准确率不适用，写为 null。相对基准的准确率差使用固定随机种子、20日移动块、500次重采样计算描述性95%区间；该方法不能修复重复查看历史、多次试验、数据错误或市场结构变化。

### 早期实测结论（历史检查点）

固定默认参数，2022年起评估1,152次可验证预测：

| 方法 | 方向准确率 | 平衡准确率 | 单边5基点后的价格指数收益 |
|---|---:|---:|---:|
| 滚动逻辑回归 | 50.43% | 50.45% | -4.43% |
| 10/30日均线 | 50.00% | 50.00% | -15.86% |
| 始终预测上涨 | 49.83% | 50.00% | +32.15% |
| 训练集多数方向 | 49.83% | 49.84% | -2.32% |

新模型相对均线的准确率差仅约 **+0.43个百分点**，描述性95%差值区间约 **[-4.69, +4.17] 个百分点**，包含零；**没有证据认定预测准确率可靠提高**。始终预测上涨的准确率低于新模型但收益更高，也说明准确率不能替代收益和风险评估。

`forecast` 的所有标签采用开盘至下一开盘，最后一根行情没有下一开盘标签而不参与预测评分；最终在最后标签日开盘平仓。这与 `backtest` 的末日收盘强制平仓口径不同，不应直接混比不同命令的收益。年度收益各自重置空仓并平仓，不能连乘还原全段结果。

整段历史此前已被查看，新模型仍是回顾性研究；概率未经独立校准，换月跳空与真实期货交易机制仍未解决。下一步需要核验逐合约行情，加入能按当时发布时间获取的库存、现货基差等信息，并在新到数据上冻结方案验证，而非继续针对这段历史调参。

本轮新增9项测试，覆盖特征时点、训练标签隔离、未来数据变动、概率稳定性、准确率与成本记账、单一类别、重采样可复现及CLI端到端运行。全部 **34 项测试**通过。
