# 甲醇量化研究学习工具

从公共日线数据开始，学习行情校验、均线信号、交易成本和回测。使用 Python 3.10+ 标准库，无需安装第三方依赖，也不需要行情 API 密钥。

## 从这里开始

在仓库目录运行：

```bash
python -m unittest discover -s tests -v
python -m methanol fetch
python -m methanol check
python -m methanol backtest --fast 10 --slow 30 --cost-bps 5
```

`fetch` 默认下载新浪财经甲醇主力连续 `MA0`，写入 `data/ma_daily.csv`。也可使用 `--symbol MA2701 --output data/ma2701.csv` 请求单合约（接口是否覆盖此合约需实际核验）。下载会覆盖指定输出文件及其来源记录；希望保留旧版本时请指定不同文件名。下载失败不会自动生成假行情。

数据下载需要允许 HTTPS 域名 `stock2.finance.sina.com.cn`。郑商所官网 `www.czce.com.cn` 可用于核验合约规则及官方数据。若出现 `Tunnel connection failed: 403 Forbidden`，请在云环境设置审核、保存网络许可并在需要时发布环境，再重试。此工具尚未实现交易所数据下载适配器。

下载成功时同时保存原始 JSONP、抓取时间、请求地址、日期范围、行数，以及原始响应和 CSV 的 SHA-256。公共接口可能改变、缺失历史或停止服务；以实际返回的日期范围为准，不保证最新、不保证与交易所一致。数据仅供本地学习，未随代码提交或重新分发。

## 查看研究结果

打开生成的 `reports/ma/report.html`（不需要启动 Web 服务）。报告还包含：

- `summary.json`：累计收益、年化收益、波动、夏普比率、最大回撤、交易数量。
- `curve.csv`：信号仓位、区间收益、策略和基准净值、回撤。
- `trades.csv`：每次入场、离场及扣除成本的区间收益。

`data/` 与 `reports/` 被 Git 忽略。本地 CSV 也能回测：

```bash
python -m methanol backtest --input /path/to/ma.csv --output reports/custom
```

必需字段：`date,open,high,low,close`；可选字段：`volume,hold,settle`。日期须是 `YYYY-MM-DD`，重复日期、缺失或非有限价格、非法 OHLC 关系会报错。读取时按日期排序，不自行填补缺失交易日或价格。

## 学习顺序与模型边界

1. **观察数据**：记录样本日期、价格区间和缺失情况；确认是主力连续还是单合约。
2. **理解策略**：10 日均线高于 30 日均线时持有，否则空仓。上一交易日收盘生成信号，下一交易日开盘执行。
3. **理解记账**：以开盘至下一开盘为一个收益区间，最后一日以收盘结束并平仓；手续费按进出各一次扣除。曲线日期是区间开始日，`interval_end_date` 是区间结束日。基准为同一期间无杠杆持有价格指数，暖机期策略空仓，基准持有。
4. **改变假设**：比较参数与成本敏感性，预先划分训练和测试日期，避免反复挑选表现最好的参数当成预测能力。本版尚未实现自动样本外划分。
5. **进入真实期货建模**：后续使用逐合约数据补充换月、合约乘数、每手手续费、保证金、逐日结算、涨跌停和成交限制。

本版计算的是**无杠杆价格指数研究收益**，不是实际期货账户盈亏。主力连续可能有拼接跳空，无法代表可以直接交易的单一合约；本版不自动修正这些跳空，交易成本的基点假设也不等于真实收费。年化采用 252 个交易日，最大回撤只在区间端点计算，夏普使用零无风险利率。请勿将结果直接用于下单。
